- 상품명: 200자 이내(모바일에서는 앞 80자만 보임). 브랜드 → 핵심 성분/% → 제품 유형 → 용량/수량 순서로 작성합니다.
- 금지 표현: "best", "#1", "cure", "treat", "anti-acne", "whitening", "FDA approved", 경쟁 브랜드명, 이모지, 프로모션 문구("20% off")

## 4. 랜딩 페이지와의 연결

- 랜딩 → Amazon 유입은 Amazon Attribution을 통해 **Brand Referral Bonus**(외부 트래픽 판매 수수료 환급, 자격 충족 시) 대상이 될 수 있습니다. Attribution 링크를 반드시 사용하십시오.
- 랜딩 페이지의 제품명, 용량, 핵심 수치는 Amazon 리스팅과 **같아야** 합니다(불일치는 광고 심사 반려와 반품의 원인이 됩니다).
- BFCM 할인은 Amazon의 **Prime Exclusive Discount / Lightning Deal / 쿠폰** 중 하나로 실제 등록해야 랜딩 배너 문구("20% off on Amazon")와 일치합니다.
