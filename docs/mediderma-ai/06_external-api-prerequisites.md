# 06. 외부 AI API 선행 정리 사항

**현재 버전은 외부 AI API 를 호출하지 않는다.** API 키·호출 비용·호출 제한이 없다. 아래는 외부 분석 API(예: Perfect Corp YouCam API, Haut.AI API, 범용 Vision LLM)를 Provider 로 추가하려 할 때 **개발 전에** 확정해야 하는 항목이다. 값은 벤더 계약에 따라 달라지므로 여기서 추정하지 않는다.

| 항목 | 확인할 것 |
|---|---|
| API 키 | 발급 주체, 서버 전용 보관 위치(브라우저 노출 금지), 키 회전 절차 |
| 비용 | 호출당 과금 단위, HD/SD 구분, 무료 구간, 월 예상 호출량 × 단가, 실패 호출 과금 여부 |
| 호출 제한 | 초당/일일 한도, 동시성, 초과 시 응답, 재시도 정책 |
| 데이터 처리 | 업로드 이미지·결과 보관 기간, 삭제 API, 학습 사용 여부(옵트아웃), 처리 리전, 하위 처리자 |
| 법적 | 개인정보 처리위탁 계약, 국외 이전 고지·동의(개인정보보호법 제28조의8), 생체정보 해당 여부 |
| 검증 | 벤더 정확도 주장의 근거(방법·표본·피부톤 분포), 자체 검증 계획 |
| UX | 전송 전 별도 동의 화면, 거부 시 기기 내 분석으로 대체, 장애 시 폴백 |

벤더별 공개 정보는 [01_competitor-benchmark.md](01_competitor-benchmark.md) 참고. 범용 Vision LLM 에 사진을 보내 점수를 받는 방식은 재현성과 근거가 없어 지시서 5항에 따라 채택하지 않는다.

## 구현 시 연결 지점

1. `src/lib/analysis/providers/<name>.ts` 에 `SkinAnalysisProvider` 구현 (`transmitsImage: true`)
2. 서버 Route Handler 로 프록시 (키는 서버 환경변수)
3. `runFaceAnalysis` 의 전송 차단을 "전송 동의가 있으면 허용"으로 변경 + 동의 UI
4. 벤더 응답을 `AnalysisResult` 스키마로 매핑 (없는 값은 null)
