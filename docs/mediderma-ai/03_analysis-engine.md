# 03. 분석 엔진 (mediderma-localcv-0.1.0)

코드: `apps/mediderma-ai/src/lib/analysis/` — `detect.ts`(브라우저) · `engine.ts` · `quality.ts` · `calibration.ts` · `compare.ts` · `simulate.ts` · `neck.ts` (순수 TypeScript, DOM 의존 없음, 결정적)

## 1. 파이프라인

1. **디코드**: EXIF 방향 반영, 긴 변 2048px 이하.
2. **얼굴 검출**: MediaPipe Face Landmarker (float16, 478점, 블렌드셰이프·변환행렬). WASM·모델을 자체 호스팅하고 CPU 델리게이트를 써서 기기별 편차를 없앤다. 최대 3명까지 세어 복수 인물을 판정.
3. **사전 품질 판정**: 얼굴 수, 자세(yaw/pitch/roll), 프레임 잘림, 얼굴 폭(px), 표정·눈 감음.
4. **정규화**: 얼굴 폭이 640px 이 되도록 얼굴 주변을 잘라 리샘플(큰 축소는 1/2 단계). 이후 모든 필터 크기는 이 좌표계 기준.
5. **마스크**: 13개 영역 폴리곤(분석 시 8% 축소), 제외 부위(눈·눈썹·입술·콧구멍, 팽창), 피부 마스크(볼·이마·코 중앙값 대비 a\*·b\* 편차와 밝기 하한 — 얼굴 자신의 피부색 기준이므로 피부톤에 대한 고정 임계값이 없다).
6. **지표 계산**(CIELAB) → **픽셀 품질 판정** → **지수·신뢰도·종합**.

## 2. 얼굴 영역

이마 중앙, 미간, 좌·우 눈가, 좌·우 눈밑, 좌·우 볼, 코, 입 주변, 좌·우 턱선, 턱 중앙 (13) + 팔자 보조 ROI(좌·우) + 목(별도 사진).
폴리곤은 Face Mesh 인덱스로 정의(`facedata.json`)하고, canonical 얼굴 모델과 실제 사진 4장에 겹쳐 그려 육안으로 확인했다. 좌/우는 본인 기준.

## 3. 지표

| 지표 | 원시값 | 방향 |
|---|---|---|
| 피부결 균일성 `texture` | 평균 \|L − blur(L, σ2.5)\| (정반사 제외) | 높을수록 균일 (100 − 지수) |
| 주름 가시성 `wrinkleVisibility` | 헤시안(σ1.6, 3.2) 어두운 선 응답의 임계 초과 평균 | 높을수록 많이 보임 |
| 팔자 부위 `nasolabialVisibility` | 같은 선 응답을 팔자 ROI 에서 | 〃 |
| 모공 가시성 `poreVisibility` | 헤시안(σ1.3) 어두운 점 응답의 국소 최대 개수 / 1000px | 〃 |
| 피부톤 균일성 `toneUniformity` | (blur σ5 − blur σ28) 의 L·a·b 표준편차 합성 | 높을수록 균일 |
| 색소·잡티 `pigmentVisibility` | blur(L,σ1.8) − blur(L,σ10) < −2.4 인 면적 비율 (선 구조·푸른 그림자 제외) | 높을수록 많이 보임 |
| 붉은 기 `rednessVisibility` | max(0, blur(a,σ5) − 얼굴 피부 a 중앙값) 평균 | 〃 (얼굴 내 상대값) |
| 눈밑 어두운 영역 `underEyeDarkness` | 같은 쪽 볼 L 중앙값 − 눈밑 L 중앙값 | 〃 |
| 광택 `shine` | 주변보다 밝고 채도가 낮은 픽셀 비율 | 참고값(컨디션 지수에 미반영) |

원시값 → 0~100 변환은 `calibration.ts` 의 `{lo, hi}` 선형 구간. 영역별 적용 지표와 가중치는 `zones.ts` 의 `ZONE_METRICS`.

**만들지 않는 값**: 수분량, 콜라겐, 피지량, 혈류, 피부 온도, 피부 나이, 탄력, 건조함(설문으로 대체). 결과 JSON 의 `analysis.notMeasurable` 에 명시하고 리포트에 "측정 불가능한 항목"으로 표시한다.

## 4. 신뢰도와 "값을 만들지 않는" 규칙

- 영역 신뢰도 = 피부 커버리지 × (선명도 · 조명 균일 · 해상도) × 자세(먼 쪽 얼굴 감점) × 표정 감점.
- 영역 신뢰도 < 0.4 → 그 영역의 모든 지표 `null` (`nullReason`: occluded / low_confidence).
- 결·선 응답이 비정상적으로 큰 영역 → 수염·머리카락으로 보고 `null` (`facial_hair`).
- 유효 영역 < 8 또는 종합 신뢰도 < 0.5 → 종합 지수 `null`, "추가 촬영이 필요합니다."
- 얼굴 폭이 작아 1.6배 이상 확대된 경우 결·모공 지표를 만들지 않는다.
- 품질 판정에서 blocker 가 하나라도 있으면 분석 결과 자체를 반환하지 않는다(영역 0개, 점수 null).

## 6. 보정 근거와 재현성 (실측)

정면 사진 1장(얼굴 폭 685px)에 변형을 가해 실제 파이프라인으로 측정했다.

| 변형 | 종합 지수 | 판정 |
|---|---|---|
| 원본 | 81 | — |
| JPEG 품질 35 / 80% 축소 / 8° 회전 / 따뜻한 색온도 | 80 / 80 / 80 / 80 | 통과 |
| 밝기 ×0.88 / ×1.12 | 83 / 77 | 통과 |
| 가우시안 노이즈 σ6 | 77 | 통과 |
| 블러 σ5·σ10, 밝기 ×0.22·×0.45·×2.2, 25° 회전, 2인, 1/5 해상도, 흑백 | — | 모두 차단 |

→ 같은 사진의 촬영·인코딩 변동에서 ±3~4점. 전후 비교의 "변화 없음" 범위를 **±6** 으로 둔 근거다. 동일 파일을 반복 분석하면 결과 JSON 이 완전히 같다(E2E Q13).

밝기가 달라지면 결·모공 지표가 같이 움직인다(어두울수록 좋게 나옴). 전후 비교에서 밝기 차가 크면 세부 지표를 "비교 불가"로 처리하는 이유다.

## 7. 한계 (검증되지 않은 것)

- **임상·통계 검증 없음.** 피부과 전문의 평가나 기기 측정값과 비교한 적이 없다. 지수의 절대값에 의미를 부여할 수 없고, 같은 조건에서의 상대 비교용이다.
- **피부톤·연령·조명별 분리 검증 미수행.** 알고리즘은 얼굴 자체 기준의 상대값을 쓰도록 설계했지만, 어두운 피부톤 정면 사진으로 끝까지 통과한 사례가 테스트 세트에 없다.
- 흐리거나 뷰티 필터가 걸린 사진은 "좋게" 나온다. 선명도 검사로 일부만 걸러낸다.
- 화장, 주근깨와 색소의 구분, 점, 그림자, 잔머리는 구분하지 못한다.
- 투명 안경은 감지하지 못한다(선글라스처럼 눈이 가려진 경우만 차단).
- 짙은 수염은 "하관 가림"으로 거부된다.
- 붉은 기는 얼굴 내 상대값이라 얼굴 전체가 고르게 붉으면 낮게 나온다.
- 목 분석은 랜드마크가 없어 화면 중앙 영역을 목이라고 가정한다(신뢰도 상한 0.6). 실제 목 사진으로 검증하지 않았다.
- 자세 각도(특히 pitch)는 정면 사진에서도 10~17° 로 나오는 경향이 있어 pitch 한도를 25° 로 넓혔다.

## 8. 전후 비교 (`compare.ts`)

- 두 결과의 촬영 요약 통계(피부 L·a·b, 좌우 밝기 차, 선명도, 자세, 얼굴 폭)를 비교해 조건 차이를 판정: 밝기(ΔL>10), 화이트밸런스(Δa>5 또는 Δb>7), 빛 방향, 선명도 비(0.65~1.55 밖), 자세(yaw>10°, pitch>12°), 해상도.
- 색 지표(톤·색소·붉은 기·눈밑)는 밝기·색·방향·자세 차이 시, 세부 지표(결·모공·주름)는 선명도·해상도·자세·밝기 차이 시 **비교 불가**.
- 비교 가능한 지표는 Δ가 ±6 이내면 **변화 없음**, 밖이면 지표 방향에 따라 **개선 방향 / 악화 방향**.
- 표시는 AFTER 를 랜드마크 닮음 변환으로 BEFORE 에 정렬한 슬라이더.
- 조명 보정은 "보정"이 아니라 "차이가 크면 비교하지 않음" 방식이다(잘못된 보정으로 개선을 만들어 내지 않기 위해).

## 9. 가상 시뮬레이션 (`simulate.ts`)

생성형 AI 를 쓰지 않는 결정적 이미지 처리. 피부 마스크 내부에서만 (1) 고주파 밝기 성분 축소, (2) 주변보다 어둡거나 붉은 중간 주파수 편차 축소를 적용한다. 픽셀 위치를 옮기지 않으므로 얼굴형·이목구비·정체성이 바뀌지 않는다. 4/8/12주 강도(0.22/0.38/0.52, 0.12/0.22/0.32)는 **시각 연출 단계**이며 임상 데이터에서 나온 값이 아니다. 개선 수치를 표시하지 않고, 모든 가상 이미지에 워터마크와 고지를 붙인다.
