# 07. 공식 사용법 영상 반영 · Gemini AI 해설

작성 기준일: 2026-11-13

## 1. 공식 사용법 영상

대상: 유니앤코어 공식 YouTube 채널 「DERMA HOME - 사용 가이드」 (`iRa1JqPJznk`, 2026-08-14 게시, 약 35분)

### 분석한 방법과 한계

| 시도 | 결과 |
|---|---|
| 자막 | 없음 (수동·자동 자막 모두 없음) |
| 영상·음성 다운로드 후 음성 인식 | **불가** — YouTube 가 자동 다운로드를 차단(403 / 봇 확인) |
| Gemini API 로 영상 직접 분석 | **불가** — 이 작업 환경에 연결된 키가 유효하지 않음 |
| 공개 미리보기 화면(약 9초 간격, 225컷) | **확인함** — 화면 구성과 순서를 눈으로 확인 |

따라서 **내레이션(음성) 내용은 분석하지 못했다.** 영상에서 말로 설명하는 사용 시간·강도·효과는 이 앱에 옮기지 않았다. 화면에서 확인한 것은 구성과 순서뿐이다.

### 화면에서 확인한 구성 (시각은 대략값)

| 구간 | 시작(약) | 화면 내용 |
|---|---|---|
| 목·어깨 관리 | 0:30 | 핸드피스를 바꿔 가며 목 뒤·옆·쇄골·어깨를 방향 도식(초록 화살표)과 함께 관리 |
| 얼굴 · 이온토포레시스 | 13:40 | 시트 마스크를 붙인 뒤 롤러형 기구로 얼굴 부위별 관리 |
| 얼굴 · 울트라소닉 | 22:04 | 제품을 손으로 바른 뒤 납작한 원형 헤드로 관리 |
| 얼굴 · RF 고주파 | 27:11 | 크림을 바른 뒤 큰 원형 헤드로 관리 |
| 관리 전·후 모습 | 32:19 | 정면·측면 전후 비교 화면 |

얼굴 구간의 순서(마스크+이온토포레시스 → 앰플+울트라소닉 → 크림+RF)는 공식 CARE GUIDE 의 "나이트 30분 케어 · 브라이트닝 버전"과 같다. 기능 구분은 화면의 헤드 모양과 타이틀 카드로 판단한 것이라 **추정**이 섞여 있다.

### 앱에 반영한 것

- 케어 섹션에 **공식 사용법 영상** 블록: 누르기 전에는 YouTube 로 요청을 보내지 않고(`youtube-nocookie`, 클릭 시 로드), 구간 버튼으로 해당 시각부터 재생.
- 추천 카드와 루틴 각 단계의 **"영상에서 보기"**: 추천된 기능에 해당하는 구간으로 이동.
- **"사용하면 무엇이 달라지는지, 내 사진으로 확인하세요"**: 추천 기능별로 공식 관리 포인트(공식 사이트 표현)와, 그 변화를 살펴볼 이 앱의 관찰 지수(현재값)를 짝짓고, 기준 저장 → 사용 → 4·8·12주 재촬영 → 전후 비교의 4단계를 안내. **효과를 단정하지 않는다.**

구간 시각을 정확히 맞추려면 영상의 실제 타임라인(또는 챕터)을 알려 주면 `src/lib/care/knowledge.ts` 의 `GUIDE_VIDEO.chapters` 만 고치면 된다.

## 2. Gemini AI 해설 (선택 기능)

### 무엇을 하나

리포트에서 이용자가 **따로 동의하고 버튼을 누르면**, 축소한 얼굴 사진(긴 변 640px JPEG)과 기기 내 엔진의 관찰 지수를 서버를 거쳐 Google Gemini API 로 보내 서술형 해설을 받는다: 한눈에 보기, 영역별 소견, 관찰 지수와의 비교(비슷함/다름/판단 어려움), 추천 케어를 쉬운 말로 풀이.

- **점수는 바꾸지 않는다.** 지수는 계속 기기 내 엔진이 계산한다. Gemini 는 숫자 점수·피부 나이·진단명을 내지 않도록 지시하고, 응답을 JSON 스키마로 강제한 뒤 서버에서 허용된 필드만 다시 걸러 낸다.
- 화면에 "생성형 AI 의견 · 점수에 반영되지 않음" 표시.
- 서버는 이미지를 저장하거나 로그로 남기지 않는다.

### 켜는 조건 (모두 충족해야 동작)

1. 서버 환경변수 `GEMINI_API_KEY` 설정 (브라우저에 노출되지 않음)
2. `/admin` → AI 모델·점수 기준 → **유료 등급 키임을 확인** 체크
3. 같은 화면에서 **Gemini AI 해설 사용** 체크
4. 이용자가 리포트에서 전송 동의 체크

기본값은 꺼짐이다. 꺼져 있으면 화면에 나타나지 않고 API 는 503 을 돌려준다.

### 선행 정리 사항

| 항목 | 내용 |
|---|---|
| API 키 | Google AI Studio 에서 발급. **결제가 연결된 유료 등급** 필요 |
| 데이터 정책 | Google 약관(ai.google.dev/gemini-api/terms): **무료 등급**은 전송 내용을 제품 개선에 사용하고 사람이 검토할 수 있으며 "개인정보를 제출하지 말라"고 명시. **유료 등급**은 제품 개선에 사용하지 않고, 오남용 탐지를 위해 한시적으로 로그 보관 |
| 비용 | 호출당 과금(이미지 1장 + 짧은 텍스트). 단가는 모델·시점에 따라 달라 여기 적지 않음 — AI Studio 요금표 확인 필요 |
| 호출 제한 | 앱 자체 제한: 세션·IP 당 분당 4회, 본문 600KB. Google 측 한도는 계정 등급에 따름 |
| 모델 | 기본 `gemini-flash-latest`, `GEMINI_MODEL` 로 변경 |
| 법무 | 얼굴 사진의 국외 이전 고지·동의, 처리위탁 계약, 개인정보 처리방침 반영 필요. EEA·영국·스위스 이용자에게는 유료 서비스만 허용(약관) |

### 검증 상태

- **실제 Gemini 호출은 검증하지 못했다.** 이 환경에 연결된 키가 유효하지 않았다(`API_KEY_INVALID`).
- 모의 Gemini 서버로 검증한 것(E2E G01~G04): 기본 꺼짐, 유료 등급 미확인 시 꺼짐, 동의 없는 요청·잘못된 이미지 거부, 동의 후 요청 형식(키 헤더·이미지·스키마·금지 지시 포함)과 결과 표시, 스키마 밖 필드(피부 나이·점수) 제거, Gemini 장애 시 오류 안내와 분석 결과 유지, 점수 불변.
- 실제 키를 넣은 뒤 응답 품질(언어, 과장 표현 여부)은 직접 확인이 필요하다.
