# 04. 개인정보 보호 · 보안

> 이 문서는 설계 설명과 검토 메모다. **법률 자문이 아니며, 출시 전 법무 검토가 필요하다.**

## 1. 데이터 흐름 요약

| 데이터 | 위치 | 보관 | 삭제 |
|---|---|---|---|
| 얼굴·목 사진 | 브라우저 메모리 | 세션 동안 | 창 닫기·새로고침·60분 미사용·"지금 삭제" |
| 랜드마크·히트맵·분석 결과 | 브라우저 메모리 | 〃 | 〃 |
| 임시 세션 ID | sessionStorage | 탭 수명 | 탭 닫기·만료 |
| (동의 시) 결과 JSON + 축소 얼굴 JPEG + 랜드마크 | 기기 IndexedDB | 기본 90일(관리자 설정) | 기록 화면에서 개별·전체 삭제, 동의 철회, 기간 경과 시 자동 |
| (동의 시) 익명 ID, 보관 동의 플래그, 언어 | localStorage | 철회 시까지 | 동의 철회 |
| 익명 이벤트 | 서버 DB | 관리자 정책 | 관리자 "오래된 로그 삭제" |
| 사용자 신고(텍스트) | 서버 DB | 〃 | 〃 |

서버로 가는 것: 이벤트 종류, 임시 세션 ID, 언어, 국가 코드(CDN 헤더), 품질 미달 사유 코드, 상위 고민 **지표 이름**, 선택 루틴·기능, 클릭한 상품 키, 저장 형식. **사진·랜드마크·점수·IP 는 저장하지 않는다.** 서버는 허용 목록에 없는 이벤트·속성을 버리고 2KB 초과 본문을 거부한다.

E2E 로 확인한 것: 분석 흐름 전체에서 POST 는 `/api/events` 뿐이고 외부 도메인 요청이 0건(모델·WASM 자체 호스팅), 동의 없이는 IndexedDB·localStorage 에 아무것도 없음, 세션 만료 시 화면에서 결과 제거, 서버 로그에 이미지·점수 문자열 없음.

## 2. 동의 설계

- (필수) 기기 내 처리 동의 — 체크 없이는 진행 불가.
- (선택) 기기 내 기록 보관 동의 — 보관 기간과 삭제 방법을 동의 문구에 표시. 리포트·기록 화면에서 나중에 켜고 끌 수 있다.
- 외부 AI 전송 동의 — **현재 전송 기능이 없어 화면도 없다.** 전송형 Provider 는 코드에서 실행이 막혀 있다.
- 기기 사용 제한(질환·임신 등) 자가 확인 — 추천 계산에만 쓰고 결과 JSON·기록·서버에 남기지 않는다.

## 3. 법규 검토 메모 (법무 확인 필요)

| 주제 | 메모 |
|---|---|
| 개인정보보호법 — 민감정보(제23조) | 얼굴 사진 자체는 일반 개인정보이나, 개인 식별 목적으로 특징점을 추출하면 생체인식정보(민감정보)다. 본 서비스는 식별·인증 목적이 아니고 랜드마크를 서버에 보내지 않지만, **기기 내 처리만으로 "수집·처리"에 해당하지 않는지** 확인이 필요하다. |
| 처리방침·고지 | `/privacy` 화면은 초안이다. 처리 목적·항목·보유 기간·파기·책임자·권리 행사 방법을 법정 기재사항에 맞춰 검수해야 한다. |
| 만 14세 미만 | 이용 불가로 고지만 한다. 연령 확인 절차는 없다. |
| 국외 이전(제28조의8) | 현재 해당 없음. 외부 AI API·해외 리전 DB 를 쓰면 발생한다. |
| 익명 통계 | 임시 세션 ID 는 탭 수명 동안의 가명 식별자다. 쿠키·유사 기술 고지 범위에 해당하는지 확인 필요. |
| GDPR | 식별 목적이 아닌 얼굴 사진은 Art.9 생체정보가 아닐 수 있으나, EU 이용자 대상이면 적법 근거·DPIA 검토가 필요하다. |
| 미국 일리노이 BIPA 등 | "얼굴 기하 스캔" 정의가 넓다. 기기 내 처리가 사업자의 "수집"인지 다툼의 여지가 있어 해당 주 서비스 시 별도 검토가 필요하다. |
| 화장품·기기 광고 | 지수·시뮬레이션이 효능·효과 표시로 읽히지 않도록 "관찰", "가상", "보장하지 않음" 문구를 고정했다. 다국어 문구는 국가별 규정(예: 중국 美白, 일본 浸透) 검수가 필요하다. 공식 상품명에 포함된 "화이트닝/Whitening"은 그대로 두었다. |

## 4. 보안

- 관리자: `ADMIN_PASSWORD` 미설정 시 전체 비활성. HMAC 서명 HttpOnly·SameSite=Strict 쿠키(8시간), 로그인 시도 제한(1분 5회, 프로세스 메모리 기준 — 다중 인스턴스에서는 공유되지 않음). 관리자 화면에 얼굴 사진이 나오는 경로가 없다(서버에 없음).
- 설정 저장 시 검증: 숫자 범위 제한, 상품·체험 URL 은 `unincore.com` 도메인만 허용.
- 헤더: `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, `Permissions-Policy: camera=(self)`.
- 개발 하네스(`/dev/harness`)는 프로덕션에서 `ENABLE_DEV_HARNESS=1` 일 때만 열린다. 운영에서는 설정하지 말 것.
- **하지 않은 것**: CSP 헤더, API 속도 제한(이벤트·신고 엔드포인트), 침투 테스트, 의존성 취약점 정리(`npm audit` 경고 미처리), 부하 테스트.
