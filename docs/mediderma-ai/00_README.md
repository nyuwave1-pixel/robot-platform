## 반드시 알아야 할 한계

1. **분석 지수는 임상 검증되지 않았다.** RGB 사진의 표면 특징을 수치화한 관찰 지수이며, 범위는 내부 테스트 이미지로 맞춘 엔지니어링 보정값이다. 정확도 수치를 마케팅에 쓸 수 없다.
2. **피부톤별 검증이 부족하다.** 테스트 사진 21장 중 품질 검사를 통과해 종합 지수가 나온 것은 2장뿐이고, 어두운 피부톤의 정면 사진은 통과 사례가 없다(고개 각도로 거부). 피부톤·연령·조명별 분리 검증은 수행하지 못했다.
3. **Safari(WebKit)·Edge·실기기 미검증.** Chromium(데스크톱·모바일 에뮬레이션)에서만 실행했다.
4. **지시서의 기술 스택 일부는 쓰지 않았다** (Python/FastAPI/OpenCV/PyTorch, Prisma, Redis, Job Queue). 이유와 확장 경로는 02 문서 참고.
5. 수염이 짙으면 "하관 가림"으로 거부된다. 뷰티 필터 적용 사진은 감지하지 못한다.
