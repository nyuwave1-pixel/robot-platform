## 2. 앱에 반영한 것

1. **제품 카탈로그 확장** (`src/lib/care/knowledge.ts`): 7종 → 12종. 가이드 단계, 기능성 표기, 낮/밤, 상세페이지가 언급하는 고민 태그를 함께 저장.
2. **제품 추천 근거** (`src/lib/care/recommend.ts` → `productReasons`): 제품 상세페이지가 언급하는 고민과 사용자의 관찰 지수·설문·관리 목표가 맞닿을 때만 추천하고, 그 근거를 카드에 그대로 보여 준다.
   - 색소·톤 → 앰플 / 글루타글로우 앰플 / 마스크 (같은 미백 단계는 최대 2개)
   - 붉은 기·민감 → 토너 패드 / 부스팅 젤
   - 건조·당김 → 미스트 / 딥 리페어 크림 / 토너 패드 / 부스팅 젤
   - 주름·탄력 목표, 팔자 부위, 목 → 딥 리페어 크림 / 퍼스트 벌스데이 크림
   - 모공·결 → 클렌징 오일 / 파우더 워시
   - 미스트·선크림은 공식 가이드의 기본 단계로 항상 안내
3. **제품 카드** (`CareView.tsx`): 가이드 단계 · 낮/밤 · 기능성 표기 · 공식 문구 · "내 결과와의 연결" · 상세페이지 요약 3가지 · 사용법 · 공식몰 링크. 카드 위에는 추천 제품을 공식 가이드 순서로 나열한다.
4. **더마홈 사용법 5단계**: 파트너 가이드 페이지의 "더마홈 사용법, 5단계로 요약"(가이드북 4쪽 기준)을 케어 탭 상단에 추가.
5. 7개 언어 번역 (한국어 기준, 나머지는 초안).

## 3. 일부러 반영하지 않은 것

- **인체적용시험 수치**: 상세페이지에 수치가 있지만 시험 조건(인원·기간·기관)과 함께 읽어야 하고 개인차가 있으므로, 앱에는 "시험 결과가 게재되어 있다"는 사실만 표시하고 수치는 공식몰에서 확인하도록 안내한다.
- **퍼스트 벌스데이 크림의 "피부 고민 설문" 표**: 페이지 각주에 예시 자료로 표기되어 있어 인용하지 않는다.
- **가격**: 변동되므로 저장하지 않는다.
- **제품과 기기의 조합 효과**: 부스팅 젤 외에는 상세페이지가 기기를 언급하지 않는다. 기기 단계별 제품은 기존 공식 CARE GUIDE 루틴만 따른다.
- 판독이 불확실했던 성분 함량·세부 문구.

## 4. 한계

- 이미지 판독이므로 오독 가능성이 있다. 출시 전 유니앤코어 담당자의 문구 검수가 필요하다.
- 고민 태그 ↔ 제품 매핑은 상세페이지 문구를 근거로 한 규칙이며, 효과를 보장하거나 임상적으로 검증한 것이 아니다.
- 상품 구성·명칭이 바뀌면 `PRODUCTS` 와 `kb.products` 를 함께 고쳐야 한다(관리자 화면에서는 노출 여부와 URL만 바꿀 수 있다).
