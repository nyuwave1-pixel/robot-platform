- **웹 데모가 강점:** 덱빌더는 2D·턴제라 브라우저 빌드가 자연스럽다 → BIT PARK / airobotphysical 포털에서 일일 시드 챌린지로 노출, 랭킹은 포인트(PP/RP) 연동.
