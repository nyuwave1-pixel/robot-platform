# ROGUE LEGENDS — 규칙 비틀기 후보와 A/B 테스트

작성 2026-11-27 · [DEVELOPMENT_PRIORITY.md](DEVELOPMENT_PRIORITY.md) §3 "브라우저 프로토타입 2~3개(서로 다른 핵심 규칙 비틀기)"를 위한 기록.

## 후보 5개 (모두 새로 생각한 규칙)
| # | 이름 | 규칙 | 판단 |
|---|---|---|---|
| 1 | 기본 (화상 반감 · 방어=공격) | 지금의 ROGUE LEGENDS | 기준선 |
| 2 | **메아리** | 전투에서 4번째 카드마다 피해·방어·상태 효과가 한 번 더 (드로우·에너지·회복은 반복 안 함), 대신 적 체력 +25% | **채택** — 설명 한 줄, 카드 내는 순서 퍼즐이 생김 |
| 3 | **밀물** | 손패가 턴을 넘어 남고, 남은 카드는 턴마다 피해·방어 +2(최대 +6). 새 카드는 손패 5장까지만 | **채택** — "아껴서 키울까, 지금 쓸까" 선택이 매 턴 생김 |
| 4 | 적 의도 돌리기 | 카드로 적의 공격 대상을 다른 적에게 돌림 | 보류 — 적이 1마리인 전투가 많아 효과가 들쭉날쭉 |
| 5 | 덱이 곧 체력 | 체력 대신 맞을 때마다 뽑을 카드가 '상처'로 바뀜 | 보류 — 재미있지만 규칙 전체를 다시 짜야 해서 2~3주 범위를 넘음 |

## 구현 (규칙 v2 안의 변형)
- `src/logic.js` `VARIANTS = ['classic', 'echo', 'tide']`. 원정의 변형은 레벨에 포함 → `src/levels.js` 끝에 `warden-echo-0` · `arcanist-echo-0` · `warden-tide-0` · `arcanist-tide-0`(인덱스 6–9) 추가. 앞의 6개는 그대로라 기존 기록·검증은 바뀌지 않음.
- 첫 화면에서 규칙 선택(변형은 난이도 0만). 밀물은 카드에 +수치 배지, 메아리는 "메아리까지 n장" 표시.
- 플레이 기록·리포트(`tools/playtest-report.mjs`)가 변형별로 따로 집계 → 같은 테스터가 세 규칙을 해 보고 비교.

## 봇 기준 균형 (탐욕 봇 300판, 난이도 0, WARDEN / ARCANIST)
| 규칙 | 1막 돌파 | 최종 승리 |
|---|---|---|
| 기본 | 34% / 31% | 7% / 5% |
| 메아리 | 57% / 47% | 14% / 9% |
| 밀물 | 39% / 32% | 7% / 5% |
메아리는 처음 버전(3번째 카드마다·전부 반복)에서 승률 63%로 너무 강해 4번째·일부 효과만·적 체력 +25%로 조정했습니다.

## 고르는 법
플레이 테스트(PLAYTEST_GUIDE.md)에서 테스터마다 세 규칙을 각 1~2판 → 리포트에서 규칙별 "다시 하고 싶은지(설문)", 판당 시간, 재방문을 비교해 하나를 주력으로 남깁니다.
