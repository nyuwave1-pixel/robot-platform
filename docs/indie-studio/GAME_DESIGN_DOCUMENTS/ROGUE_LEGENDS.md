# ROGUE LEGENDS — 게임 기획서 (MVP)

작성 2026-11-27 · 코드 `apps/game-lab/rogue-legends` · 상태 **플레이 가능한 MVP** (사람 플레이 테스트 전)

## 1. 한 줄
13층의 잿불 탑을 오르며 카드 덱을 키우고, 정상의 **잿불 거상**을 쓰러뜨리는 덱빌딩 로그라이크. 원정 하나 25–40분.

## 2. 핵심 재미 (장르 분석에서 가져온 것 / 우리가 다르게 하는 것)
| 장르의 검증된 재미 | 이 게임의 구현 |
|---|---|
| 매 판 다른 덱 — "이번엔 무슨 빌드?" | 영웅별 카드 풀 16장 + 공용 2장, 전투 보상 3장 중 1장, 상점·사건으로 넣고 빼기 |
| 적의 다음 수가 보이는 퍼즐형 전투 | 적 머리 위 **의도 표시**(공격 수치·방어·강화·약화) — 수치는 힘·약화·취약·층 보정을 반영한 실제 값 |
| 갈림길 지도에서의 위험·보상 선택 | 시드 지도: 4개 경로가 섞이는 7열 × 12층 + 보스, 정예·모닥불·상점·사건·보물 |
| 짧고 반복 가능한 원정 | 한 판 30분 안팎, 난이도 0–2 |

**차별점(우리 것)**
- **화상(burn)**: 적이 매 내 턴 끝에 화상만큼 피해를 받고 화상이 **절반으로** 줄어든다(독처럼 1씩이 아니라 반감). `불씨 키우기`(2배)·`폭발`(화상×2 피해로 소모)와 맞물려 "쌓았다가 터뜨리는" 타이밍 게임이 된다.
- **방어가 곧 공격**: WARDEN은 방어를 쌓고 `성벽 돌진`(현재 방어만큼 피해)으로 바꾼다. 판금(매 턴 방어)·가시와 엮인다.
- **원정 = 행동 기록**: 저장 파일이 곧 리플레이 증명이라 **포털 랭킹을 서버가 다시 계산해 검증**할 수 있다(치트 방지). 같은 시드로 친구와 같은 탑에 도전하는 "주간 시드"가 공짜로 생긴다(`?seed=`).

## 3. 영웅
| 영웅 | 체력 | 시작 덱 (10장) | 시작 유물 | 플레이 |
|---|---|---|---|---|
| WARDEN 성벽의 수호자 | 80 | 베기 ×5, 방패 들기 ×4, 방패 강타 | 철 휘장 (전투 시작 방어 6) | 방어·힘·가시·판금 |
| ARCANIST 잿불의 마도사 | 74 | 비전 화살 ×4, 보호막 ×4, 점화, 집중 | 꺼지지 않는 숯 (전투 시작 모든 적 화상 3) | 화상·부패·드로·에너지 |

## 4. 규칙
- 매 턴 에너지 3, 카드 5장. 쓴 카드는 버린 더미, `소멸` 카드는 이번 전투에서 사라짐, 능력 카드는 전투 내내 유지.
- 방어는 내 턴 시작에 사라짐(판금은 그 뒤에 다시 쌓음). 손은 최대 10장.
- 피해 계산: 기본 + 힘 → 약화면 ×0.75 → 대상이 취약이면 ×1.5 (내림) → 방어가 먼저 받음 → 가시는 공격자에게 반사.
- 상태: 힘·민첩·취약·약화·화상·부패·가시·판금·잿불(매 턴 모든 적 화상)·통찰(매 턴 드로 +).
- 적: 일반 5종(늪 민달팽이·놋쇠 파수기·잿가루 정령·가시등 멧돼지·그을린 신도), 정예 2종(강철 여족장·쌍둥이 초롱), 보스 잿불 거상. 행동은 정해진 순환(시작 위치만 무작위) → 외워서 대비할 수 있음.
- 깊어질수록 강해짐: 적 체력 층마다 +4%, 피해 4층마다 +1, 난이도마다 체력 +8%·피해 +1.
- 보상: 일반 골드 12–20, 정예 30–40 + 유물 + 강화 카드 1장 포함. 모닥불(회복 30% / 카드 강화), 상점(카드 4장·유물·카드 제거), 사건 3종.

## 5. 점수와 포털 보상
- 점수 = (도달 층+1)×20 + 정예×40 + 처치×5 + (승리 시 300 + 남은 체력×2 + max(0, 200−턴)).
- 등급: 승리 — 남은 체력 50%↑ S, 25%↑ A, 그 외 B · 패배 — 9층 이상 C, 그 전 D.
- airobotphysical.com RP: S 30 · A 22 · B 15 · C 8 (사이트 상한·하루 1회 규칙 적용).
- BIT PARK: 승리한 원정만 `levelClear` + proof, 레벨 = 영웅×난이도(6개), metric = 사용한 턴(낮을수록 좋음).

## 6. 밸런스 도구와 현재 값
`node tools/sim.mjs N` — 탐욕 봇(눈앞 가치만 보고 카드를 냄)이 영웅·난이도별 N판. 2026-11-27, 300판:
WARDEN 0 34% · ARCANIST 0 31% · 난이도 1 11% / 14% · 난이도 2 3% / 1%. 봇은 수를 내다보지 않으므로 사람 기준 목표는 난이도 0 승률 50–60%.

## 7. 다음 단계 (MVP 이후)
1. 사람 플레이 테스트 5명 → 카드별 선택률·승률 기록(텔레메트리는 포털 동의 후).
2. 2막·3막(새 적·보스), 카드 60장, 영웅 3번째.
3. 그래픽: 카드 일러스트(라이선스 확인된 CC0 또는 자체 제작), 전투 연출, 사운드트랙.
4. 주간 시드 리그(BIT PARK 리그 + 공유 페이지 — 포털 세션 담당).
5. 협동/PvP 모드는 행동 기록 구조 위에서 "같은 시드 동시 레이스"부터.
