## 전역 UI
- **ProgressRail**: 우측 1px 골드 라인 + 현재 챕터명(Inter 12px). 클릭 이동.
- **GoldCursor**: 데스크톱 커스텀 커서(8px 점 + 지연 링), 인터랙티브 요소 위에서 확장·라벨("DRAG", "PLAY").
- **배경 보간**: 섹션 진입 시 `--bg` 토큰 GSAP 보간, 캔버스 클리어 컬러 동기화.
- **스크롤 방향 인디케이터**: 하단 중앙 미세 화살표, 역스크롤 시 반전.
