## 4. 장면(Scene) 구성 — 단일 캔버스 + View 포털
```
<Canvas> (고정, 전체 화면, 포인터 이벤트 통과)
  <View track={s01Ref}> HeroScene      </View>
  <View track={s02Ref}> TwentyEight    </View>
  <View track={s03Ref}> ProductInspect </View>   ← 유일하게 포인터 이벤트 수신
  ... (섹션별 View)
```
- drei `View`로 DOM 섹션과 3D 뷰포트를 묶어 **캔버스 1개**만 유지(컨텍스트 로스트 방지, 모바일 GPU 메모리 절약).
- 공유 에셋: 용기 GLB 1개, 환경맵 1개(KTX2), 파티클 텍스처 1개. 섹션별 머티리얼 변형만.
- 섹션 비가시 시 `frameloop="demand"` + 해당 View 렌더 중지.

## 6. 제작 파이프라인
1. 영상에서 레퍼런스 프레임 추출(4K): t=13s(개봉), 20s(개봉 완료), 32~44s(용기 정면/클로즈업), 56s(박스 닫힘) — 샌드박스에서 추출 검증 완료, 개발 단계에서 저장소 `apps/unicore-birthday/reference/`에 보관
2. 디칼 SVG 작성 → 원본 프레임 위에 오버레이 비교(정합 오차 1% 이내)
3. 프로시저럴 모델 → GLB 익스포트(Draco) → `gltf-transform`으로 KTX2 텍스처 압축
4. 사진 2장·영상 프레임과 렌더 결과 **나란히 비교 검수**(색·비율·반사)
5. 품질 프리셋 3단계(HIGH 2048 텍스처·파티클 3000 / MID 1024·1000 / LITE 512·300, 투과 머티리얼 → 불투명 대체)
6. WebGL 미지원: 영상에서 추출한 36프레임 스프라이트 시퀀스(용기 360° 대체 — 영상 회전 컷이 부족하면 프로시저럴 모델 사전 렌더)

## 7. Spline MCP 연동 계획 (사용자 연결 시 실행)
1. 사용자가 Spline 계정 로그인 및 MCP 서버 등록 → 이 세션에서 툴 목록 재확인
2. 케이크·PDRN 구체·4GF 구조 3개 장면을 Spline에서 생성, 머티리얼·라이팅 설정
3. `.splinecode` 공개 URL 발급 → `@splinetool/react-spline` 로 섹션에 임베드(lazy)
4. 성능 측정 후 Three.js 버전과 A/B — 더 가벼운 쪽 채택
5. Spline 장면이 로드 실패하면 Three.js 버전으로 자동 폴백

## 8. 제품 뚜껑 분리·내부 크림
