# 08. 개발 일정 및 단계별 완료 기준

전제: 승인 후 착수, 1인 풀스택 + 디자이너(Canva 케이크 영상) 협업. 총 **7주**. 각 단계는 Vercel Preview URL로 검수합니다.

| 단계 | 기간 | 산출물 | 완료 기준(Definition of Done) |
|---|---|---|---|
| **P0 승인** | D0 | 이 기획 패키지(00~08) 검토·결정 사항 회신 | 11절 결정 항목 5개 확정 |
| **P1 디자인 시스템** ✅ v0.2 제출 | 1주 | Figma(또는 HTML) 시안: 인트로 3컷, 히어로, S03, S04, S06, 모바일 3컷. 토큰·타이포·모션 스펙 | 데스크톱·모바일 시안 승인, 폰트 라이선스 확정 |
| **P2 스캐폴드 + 콘텐츠 데이터** | 0.5주 | `apps/unicore-birthday` Next.js 15 앱, `src/data/*` 원문 입력(01 문서 2절), SEO 메타·JSON-LD, SSR 텍스트 버전 전체 페이지 | 3D 없이도 전 섹션 텍스트·이미지가 읽히는 페이지, Lighthouse SEO 100 |
| **P3 3D 제작** | 1.5주 | 용기·박스 GLB(디칼 정합), 파티클, 분자 3종, 케이크 폴백, 품질 프리셋 3단계 | 사진·영상 프레임과 나란히 비교 승인, 모바일 MID 프리셋 60fps(중급기) |
| **P4 모션 개발** | 1.5주 | Lenis+ScrollTrigger 전 섹션 스크럽, 핀, 텍스트 모션, 배경 보간, 커서, 인스펙터 인터랙션 | 스크롤 정지/재개 시 진행 상태 유지, 스크롤 점프 0건, reduced-motion 모드 |
| **P5 영상·오디오** | 0.5주(+Canva 제작 병행) | 영상 트랜스코딩 세트, VideoBlock, AudioController, 인트로 3단계, 케이크 영상 연동 | 자동재생 정책 테스트(iOS/Android/Chrome) 통과, 스킵 항상 가능 |
| **P6 반응형·성능** | 1주 | 모바일 전용 경험, 고정 CTA, 적응형 렌더링, 이미지/모델 압축, 코드 스플리팅 | LCP ≤2.5s, CLS ≤0.1, INP ≤200ms(모바일 4G 프로파일), 번들 초기 JS ≤180KB gz |
| **P7 QA·배포** | 1주 | 브라우저/기기 매트릭스 QA, WebGL 미지원·영상 실패 폴백 검증, 성능 보고서, 배포 | 11장 QA 체크리스트 전 항목 통과, 도메인 연결 |
