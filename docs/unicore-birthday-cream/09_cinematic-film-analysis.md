## 4. 영상 반영 설계 — "스크롤 스파인"
이 필름은 사이트 섹션 순서와 거의 1:1로 대응하므로, 단순 인트로 재생을 넘어 **섹션별 구간을 스크롤에 동기화**해 사용합니다.

| 사이트 | 필름 구간 | 사용 방식 |
|---|---|---|
| I-01 → I-03 (인트로) | 0–62초 전체 | 자동재생(muted). 12초에서 일시정지하고 SOUND 게이트 → 선택 후 12–62초 소리와 함께 이어서 재생. 스킵 시 59초 로고 컷 0.8초 후 S01 |
| S02 The 28 Days | 26.0–31.5 | 핀 섹션에서 `currentTime`을 스크롤 진행률에 매핑(스크럽). 번인된 28 숫자 대신 HTML 3D 숫자를 위에 올리고, 영상은 26.0–28.5 구간(숫자 등장 전)만 스크럽 |
| S04 Clinical | 31.5–38.0 (캡 매크로) | 32.4초 clean 프레임부터 스크럽, HTML 카운트업 숫자 오버레이. 19.06%는 영상 대신 HTML+3D 바 |
| S05 Masterpiece | 18.5–26.0 | **영상 스크럽이 3D 박스 리깅을 대체** — 박스 개봉 자체가 이 구간. 3D 박스는 S03 인스펙터 전용으로 축소 |
| S06/S07 Ingredients·PDRN | 45.5–49.5 | 입자 수렴 구간 스크럽 → 49.5초 분자 정지 프레임 위에 HTML 라벨 |
| S12 Final | 51.5–57.5 | 배경 재생(라벨 영역 블러 마스크), HTML 카피 오버레이 |
| S01 Hero | 0–3.8 | 루프 배경(촛불), 3D 타이포 전경 |

구현: 영상 1개를 `public/video/film_1080.mp4`(+WebM)로 두고 섹션마다 `<video>` 인스턴스 대신 **단일 비디오 + 뷰 포털**(캔버스에 `drawImage`)로 그려 디코더 1개만 사용. iOS Safari는 `currentTime` 스크럽 시 키프레임 간격(GOP)이 길면 끊기므로 빌드 시 `-g 12`(0.5초 GOP)로 재인코딩한 스크럽 전용 파일을 별도 생성(용량 약 1.6배). 스크럽 구간이 짧아 `preload="auto"` 허용.

## 5. 교체되는 결정
- S05 선물상자 **3D 리깅은 2순위로 강등**(영상 스크럽으로 대체). 3D 작업은 S03 제품 인스펙터(용기)에 집중.
- 인트로 영상은 `임상강조_벌스데이` 대신 **시네마틱 필름 v1**을 메인으로. 임상강조 영상은 S04 보조(모달 "영상으로 보기")와 모바일 세로 버전(세로 시네마틱 필름 제작 전까지)으로 사용.
- B-roll 12클립은 이 필름의 소스이므로 개별 사용은 S03(실크), S09(크림), S13(화이트 박스) 등 필름에 없는 구간에 한정.
