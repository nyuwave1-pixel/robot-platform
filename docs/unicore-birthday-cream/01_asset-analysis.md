## 2. NAS 경로(`\\unincore_NAS\영상제작\영상소스\벌스데이작업`)에 대하여

이 세션은 클라우드 격리 컨테이너에서 실행됩니다. 사내 NAS(SMB 공유)는 사내망에만 존재하므로 클라우드에서 직접 마운트할 수 없습니다. 실제로 확인한 결과:

- 컨테이너에는 `smbclient`, `mount.cifs`가 없고, 외부 네트워크도 npm 레지스트리 외에는 차단되어 있습니다.
- Remote Control(사용자 PC 폴더 공유) 목록을 조회했으나 등록된 폴더가 없습니다.

### 경로를 "인식해서 작업"하기 위한 3가지 방법 (하나만 선택)

| 방법 | 절차 | 장점 | 단점 |
|---|---|---|---|
| **A. Remote Control (권장)** | NAS가 마운트된 PC에서 Claude 데스크톱 앱 → Settings → Claude Code → Remote Control에 `벌스데이작업` 폴더(또는 로컬 복사본) 등록 → 이 세션에서 폴더 요청 | 원본 그대로 분석(ffprobe, OCR) 가능, 대용량 영상도 OK | 해당 PC가 켜져 있어야 함 |
| B. 저장소 업로드 | 상세페이지 JPG는 git에 커밋, 영상은 Git LFS 또는 별도 스토리지(Vercel Blob/Supabase Storage/Google Drive) | 간단 | 영상은 git에 직접 올리면 안 됨(용량) |
| C. Google Drive 공유 | Drive에 폴더 업로드 후 공유 → 이 세션의 Google Drive 커넥터로 읽기 | PC 없이 가능 | 영상 파일 메타데이터만 읽히고 바이너리 분석은 제한될 수 있음 |

> 지시문 원칙에 따라 **영상이 확인되지 않은 상태에서 임의 영상을 원본인 것처럼 사용하지 않습니다.** 인트로 03(제품 필름) 구간은 플레이스홀더 + 제품 이미지 기반 모션 그래픽 폴백으로 설계했습니다(`06_video-audio-system.md`).

## 3. 제품 사진 분석 (디자인 기준 자료)

### 3.1 용기 (Jar)
- 형태: 원통형 자(Jar). 상단 **브러시드 샴페인 골드 금속 캡**(동심원 헤어라인 가공, 중심 하이라이트), 하단 **스모키 다크 브라운 반투명 유리/아크릴 바디**.
- 캡과 바디 비율 ≈ 1 : 1.25 (높이 기준). 캡 하단에 얇은 골드 밴드로 바디와 분리.
- 바디 인쇄(골드 호일, 중앙 정렬):
  - `1ST BIRTHDAY CREAM` (ST는 윗첨자, 산세리프, 대문자, 자간 넓음)
  - `SKIN RE:BIRTH` (소형, 산세리프)
  - `UNI&CORE` (하단, 산세리프, 자간 넓음)
- 바디 내부에 크림이 비치는 듯한 그라데이션(위 밝음 → 아래 어두움).
- 3D 변환 가능성: **높음**. 원통 + 캡은 프로시저럴 모델링으로 정확히 재현 가능. 인쇄 텍스트는 원본 비율로 디칼(Decal) 텍스처 처리. 뚜껑 분리/내부 크림 노출은 실제 내부 구조 사진이 없으므로 **구현 보류**.

### 3.2 패키지 (Gift Box)
- 구조: 정육면체에 가까운 **양문형(Double-door) 개봉 박스**. 외부는 **화이트 엠보싱(미세 격자 텍스처) 종이**, 상판·내부 전면은 **골드 호일**.
- 전면 라벨: 브러시드 골드 금속 플레이트. 인쇄 요소:
  - 상단 `III` (세로 바 3개 — 브랜드 마크로 추정, 의미 확인 필요)
  - `1st Birthday Cream` (세리프, 이탤릭 느낌)
  - `Skin Re:birth` (산세리프)
- 하단 띠: `NET WT. 1.76 oz` (좌) · `UNI&CORE` (중앙, 세리프, 골드) · `50 g` (우)
- 내부: 골드 받침대 중앙에 용기가 안착.
- 3D 변환 가능성: **높음**. 박스 6면 + 도어 2장 + 받침대로 리깅 가능 → "SECTION 05 THE MASTERPIECE"의 박스 개봉 애니메이션에 직접 사용.

### 3.3 두 사진의 로고 표기 차이 (확인 필요)
| 위치 | 서체 | 표기 |
|---|---|---|
| 용기 바디 | 산세리프 | `UNI&CORE` |
| 박스 하단 띠 | 세리프 | `UNI&CORE` |
| 박스 라벨 | 세리프 이탤릭 | `1st Birthday Cream` (소문자 혼용) |
| 용기 | 산세리프 | `1ST BIRTHDAY CREAM` (대문자) |

→ 사이트에서는 **용기 인쇄 표기(`1ST BIRTHDAY CREAM` / `SKIN RE:BIRTH` / `UNI&CORE`)를 제품명 기준**으로, 박스 라벨 표기는 세리프 디스플레이 헤드라인용으로 각각 그대로 보존합니다. 공식 로고 벡터(AI/SVG) 파일이 있다면 함께 제공해 주십시오. 없으면 사진에서 비율을 측정해 재현하되 임의 수정은 하지 않습니다.

## 4. 상세페이지 콘텐츠 (OCR 대기)

상세페이지 JPG가 없어 OCR을 수행하지 못했습니다. 지시문에 기재된 수치·문구는 **"지시문 출처"로 분리 관리**하고, 원본 상세페이지와 임상보고서로 대조하기 전까지는 사이트에 노출하지 않습니다.

| 항목 | 지시문 값 | 대조 상태 | 노출 전 필요 자료 |
|---|---|---|---|
| 볼 리프팅 개선율 | 48.33% | ⏳ 미대조 | 인체적용시험 결과보고서(시험기관, n, 기간, 측정장비) |
| 목 주름 감소율 | 19.06% | ⏳ 미대조 | 동일 |
| 4주 사용 만족도 5개 항목 | 100% | ⏳ 미대조 | 설문 대상 수, 문항 원문 |
| 인삼 유래 PDRN 순도 | 99% | ⏳ 미대조 | 원료사 CoA/스펙시트, 처방 근거 |
| 28일 주기 | 14일+14일 | ⏳ 미대조 | 상세페이지 원문 (스토리텔링으로만 사용) |
| 성분 4종 | PDRN / EGF·IGF·FGF·KGF / 아세틸헥사펩타이드-8 / 시카 카밍 콤플렉스 | ⏳ 미대조 | 전성분표 |
| 수분·장벽 | 우레아, 세라마이드 | ⏳ 미대조 | 전성분표 |
| 사용법 3단계 | 지시문 원문 그대로 | ✅ 사용 가능 | – |

OCR 파이프라인(자료 도착 시 즉시 실행): JPG → 구간 분할(섹션별 크롭) → 한국어 OCR → `src/data/*.ts`에 "원문 그대로" 입력 → 사람 검수 체크리스트 → 사이트 반영.

## 5. 영상 분석 체크리스트 (자료 도착 시)

```bash
ffprobe -v error -show_entries format=duration,size:stream=codec_name,width,height,r_frame_rate,pix_fmt,sample_rate,channels -of json <파일>
```

확인 항목: 해상도·비율(16:9 / 9:16 / 1:1), 길이, 프레임레이트, 오디오 트랙 유무·채널, 색공간(HDR 여부), 첫/마지막 프레임(전환 설계용), 로고 등장 타임코드(스킵 포인트 설계용).

## 6. 결론 및 요청 사항

1. **상세페이지 JPG, 제품 영상, (가능하면) 로고 벡터·임상보고서·전성분표**를 2절의 A/B/C 중 한 방법으로 전달해 주십시오.
2. 그 전까지는 사진 2장만으로 확정 가능한 부분(용기·박스 3D, 컬러, 타이포 방향, 사이트 구조)을 기준으로 기획을 완성했습니다.
3. `III` 마크의 의미(브랜드 심볼인지, 라인업 번호인지)를 알려주시면 로고 사용 규칙에 반영하겠습니다.
