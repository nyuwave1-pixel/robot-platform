## 3. 레이아웃 그리드
- Desktop: 12컬럼, 거터 24px, 좌우 여백 clamp(32px, 5vw, 96px). 텍스트 최대 폭 56ch.
- Mobile: 4컬럼, 거터 16px, 좌우 여백 20px. 텍스트 최대 폭 100%.
- 모든 핀 섹션은 `100svh`(iOS 주소창 변동 대응), 인트로 오버레이는 `100dvh`.

## 4. 스크롤 길이 설계 (총 높이)
| 구간 | Desktop | Mobile |
|---|---|---|
| S01~S12 핀 합계 | 약 38 × 100vh | 약 23 × 100svh |
| 예상 스크롤 시간 | 2~3분 | 1.5~2분 |
스크럽 섹션 사이에 50vh의 "숨 고르기" 일반 섹션을 두어 터치 스크롤 피로를 줄입니다.

## 5. 터치 제스처 충돌 방지 규칙
1. 인스펙터 View 위에서 **수평 이동이 우세(|dx| > |dy|×1.5)** 할 때만 회전, 그 외는 브라우저 스크롤에 양보(`touch-action: pan-y`).
2. 핀치 줌은 인스펙터 내부에서만 `touch-action: none` 전환(2핑거 감지 시).
3. 수평 스크럽(S06)은 모바일에서 사용하지 않음(세로 스냅으로 대체).
4. 하단 고정 CTA는 가로 스와이프 무시.

## 6. 성능 가드 (모바일에서 콘텐츠가 늦게 나타나지 않도록)
- 모든 텍스트·수치·각주는 **SSR HTML로 즉시 렌더**, 캔버스는 `IntersectionObserver` 진입 500px 전 lazy mount.
- 3D 로딩 중에도 섹션은 텍스트 + 정적 포스터(제품 실사 WebP)로 완성 상태.
- LCP 후보는 히어로 텍스트 또는 포스터 이미지(≤120KB WebP, `priority`).
- 영상은 `preload="metadata"`, 진입 시 `play()`, 이탈 시 `pause()` + `src` 해제(모바일 디코더 자원 반환).
- 폰트: Pretendard Variable 서브셋 woff2(≤300KB), `font-display: swap`, 사이즈 조정 폴백(`size-adjust`)으로 CLS 방지.

## 7. 모바일 전용 인트로 흐름
```
블랙 → 골드 입자(CSS/Canvas2D, 60개) → 세로 케이크 컷(Canva 세로 버전 또는 폴백) → SOUND 게이트(풀폭 버튼 3개, 각 52px)
→ 세로 제품 영상(9:16 원본) → S01
```
저전력 모드·데이터 세이버(`navigator.connection.saveData`) 감지 시 영상 대신 포스터+타이포 시퀀스로 자동 전환, 안내 토스트 1회.

## 8. 접근성·가독성 체크
- 골드 텍스트(#C6A16A on #080706) 대비 7.1:1 — 본문 가능. 골드 on 브론즈(#38231C) 3.9:1 — 18px 이상 굵게만 사용.
- 모든 인터랙티브 요소 44×44 이상, 포커스 링 골드 2px.
- `prefers-reduced-motion`: 스크럽 → 정적 상태, 영상 자동재생 금지, 파티클 정지.
- 스크린리더: 캔버스 `aria-hidden`, 섹션별 `h2`, 수치는 `<data value>`로 마크업.
