# Character Design Guide

## 방향
첫인상은 **작고 둥글고 사랑스럽게**, 성장할수록 **길고 정돈된 실루엣**으로. 얼굴 크기만 키우거나 색만 바꾸지 않고 **프로포션 자체**를 바꾼다.

## 공통 리그
모든 단계가 같은 피벗 구조를 쓴다: `root → (legL, legR) / upper → (armL, armR, head)`.
헤어·의상·액세서리는 이 피벗과 치수(`bodyDims`)에 매달려 있어 **단계가 바뀌어도 커스터마이징이 그대로 유지**된다. 나중에 GLB 로 교체할 때도 같은 본 이름을 쓰면 된다.

성장 시네마틱 동안 `growth` 값이 n → n+1 로 `smootherstep` 보간되며 모든 치수가 연속적으로 변한다(모델 팝 교체가 아닌 블렌딩). 허리 비율·눈 위치·코 돌출·블러셔 크기도 같은 값으로 보간된다.

스타일라이즈드 캐릭터이므로 성인 단계도 실제 인체 비율이 아니다. **성장 단계는 체형의 우열이 아니라 스타일의 변화**로 다룬다.

## 얼굴
- 눈: 구면에 접하는 원판 레이어(아웃라인·흰자·홍채·하단 반사·동공·하이라이트 2개). 어릴수록 홍채가 눈 전체를 채운다.
- 눈 모양 3종(동그란/아몬드/웃는), 눈썹 3종, 얼굴형 3종, 입술 색 5종.
- 표정: `smile`(기본, 깜빡임) / `happy` / `relaxed`(케어 중 눈 감음).

## 애니메이션
`idle`(호흡·고개 기울임·깜빡임) · `walk` · `sit` · `lie` · `wave` · `pay` · `pose`(cute/model/heart). 목표 회전값으로 프레임마다 lerp → 상태 전환이 자연스럽게 블렌딩된다. 헤어 꼬리(트윈·포니테일·웨이브)는 이동 시 뒤로 젖혀지는 2차 모션.

## 단계별 스타일 가이드 (아트 교체 시 기준)
- 1~2: 소프트 핑크 · 크림 화이트 · 파스텔 라벤더. 퍼프 소매, 리본.
- 3: 피치 베이지, 라운지 매니저 유니폼(크림 + 골드 트림).
- 4~5: 샴페인 골드 · 프리미엄 블랙. 골드 벨트, 티아라, 롱 가운, 상시 스파클.

## 다양성 원칙
피부 톤은 모두 같은 조건으로 선택 가능하고 어떤 톤도 "성장 결과"로 취급하지 않는다. 광채 연출은 톤을 밝게 바꾸지 않고 에미시브 강도만 올린다.
