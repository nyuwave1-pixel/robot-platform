# MEDIDERMA LOUNGE — Game Design Document

> BEAUTY LIFE. BEAUTY GROWTH. BEAUTY SOCIAL.
> 장르: 3D 캐릭터 육성 · 뷰티 시뮬레이션 · 라운지 경영 · 소셜

이 문서는 **현재 구현된 것(v0.1 MVP)** 과 **이후 단계 계획**을 구분해서 적는다. `[구현]` 표시는 저장소 코드에 실제로 들어 있는 기능이다.

## 1. 한 줄 콘셉트
작고 귀여운 캐릭터를 만나, UNI&CORE 제품과 DERMA HOME 디바이스로 직접 케어하며 5단계에 걸쳐 성장시키고, 나만의 메디더마 라운지를 키워 가는 게임.

## 2. 핵심 루프 `[구현]`
1. 캐릭터 생성(이름·피부 톤·헤어·눈) → 라운지 입장
2. DERMA HOME 존에서 공식 루틴을 고른다 (브라이트닝 / 링클 / 카밍 / 외출 전 5분 2종 / 두피 / 바디)
3. 스텝마다 **공식 조합 제품을 바르고 → 부위를 선택 → 디바이스 헤드를 문질러** 게이지를 채운다
4. Skin / Device / Knowledge EXP + BEAUTY COIN 획득
5. 누적 EXP 가 단계 기준에 닿으면 **성장 시네마틱**(프로포션 블렌딩 + 파티클 + 플래시)
6. 고객 NPC 가 방문 → 상담(루틴 추천) → 익스프레스 케어 → 만족도 → 결제 → 단골·SNS 후기
7. 코인·LOUNGE POINT 로 라운지 확장, 가구 배치, 테마 변경
8. 포토존·셀피 → 뷰티 피드 게시 → SOCIAL STAR → 패션 해금

## 3. 성장 시스템 `[구현]`
| 단계 | 이름 | 누적 EXP | 연출 |
|---|---|---|---|
| 1 | BABY BEAUTY | 0 | SD 비율, 큰 눈, 짧은 팔다리 |
| 2 | LOVELY GIRL | 120 | 비율 성장, 헤어·패션 확장 |
| 3 | BEAUTY LADY | 420 | 성인 비율, 글램 웨이브·유니폼 해금 |
| 4 | PREMIUM BEAUTY | 950 | 골드 벨트, 블랙 드레스·티아라 해금 |
| 5 | MEDIDERMA ICON | 1800 | 상시 스파클 오라, 샴페인 골드 가운 |

- EXP 6종: Skin Care / Device Care / Beauty Knowledge / Social / Fashion / Lounge. 합계가 단계 기준.
- **시간 경과로는 성장하지 않는다.** 모든 EXP 는 플레이어 행동(케어·고객·게시·구매·확장)에서만 나온다.
- 한 번에 여러 기준을 넘어도 시네마틱은 한 단계씩 재생된다.
- 표현 원칙: "제품을 쓰면 외모가 좋아진다"가 아니라 **게임 EXP 에 따른 판타지 연출**. 스플래시·케어 결과·도감에 고지 문구를 넣었다. 피부 톤·생김새에 우열을 두지 않는다(생성 화면 고지).

## 4. DERMA HOME 케어 `[구현]`
- 3모드: RF(엠버 파티클) / ULTRASONIC(물결 링 + 미세 진동) / IONTOPHORESIS(스파크)
- 부위: 이마·볼·턱선·목·두피·바디. 3D 마커를 누르거나 칩으로 선택.
- 루틴·스텝·제품 조합·분 표기는 더마홈 공식 가이드 표를 그대로 옮겼다. 게임에서는 "공식 가이드 N분 → 게임 축약"으로 표시하고 실제 시간은 요구하지 않는다.
- 페이스 루틴은 공식 가이드대로 **미스트 마무리**(보너스 EXP).
- 프리 케어: 모드 1개만 골라 체험.

## 5. 라운지 경영 `[구현]`
- 등급 5단계(MY MINI → GLOBAL FLAGSHIP). 방 크기·동시 고객 수·존이 확장된다.
- 공간: 입구 / 리셉션 / 상담 소파 / DERMA HOME 존 / 제품 진열 / 화장대(캐릭터) / 포토존(Lv2) / 헤드 스파(Lv2) / 바디 케어(Lv3) / VIP 룸(Lv4) / 소셜 라운지(Lv5)
- 인테리어: 가구 12종 구매 → 보관함 → 편집 모드에서 배치·이동·회전·보관. 바닥·벽·조명 테마.
- 파트너 사이트의 사업 모델(판매 장려금 등)은 **게임 수치로 옮기지 않았다.** 실제 수익을 연상시키는 표현을 피하기 위해서다.

## 6. 고객 NPC `[구현]`
8유형(초보·직장인·인플루언서·크리에이터·두피 관심·프리미엄·관광객·VIP), 등급별 해금. 유형마다 선호 루틴·결제액·재방문 성향이 다르다. 애니메이션: 걷기·착석 대기·누워 케어·결제·퇴장. ★4 이상이면 단골 등록 + 후기 게시물 생성.

## 7. 경제 `[구현]`
| 재화 | 획득 | 사용 |
|---|---|---|
| BEAUTY COIN | 케어, 고객 결제, 퀘스트 | 제품·패션·인테리어·라운지 확장 |
| LOUNGE POINT | 고객 만족도 | 라운지 확장 조건 |
| SOCIAL STAR | 게시·친구 방문·퀘스트 | 스페셜 패션·인테리어 |
| BEAUTY GEM | 성장 단계·퀘스트·확장 | 프리미엄 아이템 |

현금 결제·확률형 아이템·현금성 보상은 **없다**. 도입 시 법률·플랫폼 정책을 별도 검토한다.

## 8. 소셜
- `[구현]` 기기 내부 SNS: 셀피(3D 캡처) 게시, 스토리 텍스트, 좋아요, 댓글, 팔로워, 데모 친구 3명, 친구 라운지 방문, 데모 랭킹.
- `[미구현]` 실제 사용자 간 피드·채팅·선물·글로벌 랭킹·국가별 커뮤니티 → 서버가 필요한 Phase 4~5.
- 데모 계정·게시물에는 `DEMO` 배지를 붙여 실제 사용자와 구분한다.

## 10. 알려진 한계
- 캐릭터는 프리미티브 조합의 프로시저럴 모델이다. "실사형 피부 셰이더·SSS·천 시뮬레이션·본 기반 헤어 물리"는 들어 있지 않다(가짜 SSS 에미시브, 사인파 헤어 흔들림으로 대체). 고품질 리깅 모델은 에셋 파이프라인 문서의 절차로 교체한다.
- 아이템 선물하기, 제품 조합 보너스, 시즌 이벤트는 미구현.
- 사운드 없음.
- 친구 초대는 서버가 없어 코드 형식만 확인한다. 같은 코드를 지어내 입력해도 보상을 받을 수 있고, 초대한 쪽이 자동으로 보상을 받지도 않는다.
- 새 그래픽은 실제 GPU 기기에서 성능을 재지 못했다. 낮은 품질 모드도 이전보다 무거워졌다.
- 펫과 직원은 가구·고객을 피해 걷지 않는다.
