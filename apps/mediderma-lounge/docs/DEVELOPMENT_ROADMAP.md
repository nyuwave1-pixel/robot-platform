## 다음 작업 제안 (우선순위 순)
1. **브랜드 검수** — 제품 DB·디바이스 모델·고지 문구를 UNI&CORE 담당자가 확인. 7개 언어 번역과 공식 제품명 번역 기준 확정.
2. **아트 교체 1차** — DERMA HOME 과 주력 제품 9종을 Blender 모델로(GAME_ASSET_PIPELINE.md).
3. **캐릭터 GLB** — 공통 스켈레톤 + 5단계 메쉬, 표정 블렌드셰이프.
4. **사운드** — BGM, 케어 모드별 효과음, 성장 연출.
5. **백엔드 v1** — 계정, 세이브 동기화, 케어 완료 서버 검증 → 이후 실제 SNS.
6. **자동 테스트** — 케어 세션 상태 전이(`store/care.ts`)와 세이브 병합 단위 테스트, Playwright 스모크.

## 서버 도입 시 권장 구성 (설계안)
Node.js + TypeScript / PostgreSQL + Prisma(계정·캐릭터·라운지·인벤토리·재화 원장·퀘스트·SNS) / Redis(세션·랭킹) / WebSocket(라운지 방문·채팅). 무료 사용량 한도 안에서 시작하려면 정적 호스팅(Netlify·Vercel·Cloudflare Pages) + 서버리스 DB 조합부터 검토한다.
