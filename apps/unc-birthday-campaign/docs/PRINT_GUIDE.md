# 인쇄 출력 가이드

## 출력 파일 구성

| 파일 | 내용 |
|---|---|
| `…_CMYK.pdf` | 인쇄소 입고용. 아트(배경·제품·효과)는 지정 dpi의 CMYK JPEG(q90, 4:4:4), 텍스트·로고·QR은 CMYK 벡터 패스(폰트 미포함, 아웃라인) |
| `…_RGB-preview.jpg` | 검수·공유용 RGB 미리보기 (최대 가로 2400px) |
| `…svg` | 편집용 원본 (mm 단위, 이미지 내장) |

## PDF 박스

- MediaBox = BleedBox = 재단 크기 + 사방 3mm
- TrimBox = 재단 크기 (예: A4 → 210×297mm, 원점 3mm 안쪽)
- 배경은 재단 여유 끝까지 채우고, 텍스트·로고·QR은 안전영역(재단선에서 판형별 5~8%) 안에만 둡니다.

## 색상

- 래스터 아트는 sRGB에서 ICC 기반으로 CMYK 변환합니다(sharp/libvips + LittleCMS). 기본 프로파일은 Ghostscript `default_cmyk.icc`(코팅지, TAC 약 300%)입니다. 블랙 배경은 약 C74 M68 Y66 K89 리치 블랙으로 분해됩니다.
- 벡터 텍스트 색도 같은 ICC 변환으로 계산합니다. 아이보리 텍스트는 거의 흰색에 가깝고, 골드 강조는 단색 샴페인 골드로 출력합니다.
- QR 모듈은 단색 K100으로 출력해 판 어긋남에 따른 스캔 실패를 막습니다.
- 인쇄소가 Japan Color 2001 Coated나 FOGRA39/51을 요구하면 `UNC_CMYK_ICC=<프로파일 경로>`로 다시 출력하세요.
- 금박·별색(Pantone)이 필요하면 RGB 미리보기와 SVG를 인쇄소에 함께 전달하고, 골드 텍스트 레이어(`data-el="*-accent"`)를 별색 판으로 지정하도록 요청하세요.

## 해상도

출력 dpi는 규격별로 지정되어 있습니다(`docs/PLATFORM_SPECS.md`). `exports/QA_REPORT.md`의 "인쇄 원본 해상도" 표는 최종 크기에서 원본 제품·배경 이미지가 몇 ppi인지 보여 줍니다.

- A·POP 계열(300dpi)은 제품 원본(약 3.9K px)이 실제 출력 크기에서 300ppi 이상이 되도록 배치됩니다.
- 현수막·백월·무대처럼 큰 판형은 배경 원본(최대 3840px)이 최종 크기에서 20~40ppi 수준입니다. 2m 이상 떨어져 보는 실사 출력에서는 통상 허용되는 범위지만, 고급 원단이나 근거리 관람 용도라면 배경 플레이트를 더 높은 해상도로 다시 생성하거나 업스케일하는 것을 권장합니다.

## 입고 전 체크

1. `npm run qa` 결과에서 실패 0건 확인
2. Acrobat 출력 미리보기(또는 `gs -sDEVICE=inkcov`)로 잉크 분판 확인
3. 롤업 하단 120mm 거치대 영역에 중요한 요소가 없는지 확인 (가이드 표시: `GUIDES=1 npx tsx scripts/preview.ts …`)
4. QR을 실제 휴대폰으로 스캔해 언어별 URL(`/`, `/en`, `/zh`)로 열리는지 확인
