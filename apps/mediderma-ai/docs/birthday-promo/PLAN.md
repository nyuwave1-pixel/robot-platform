## 2. 진입 시퀀스 (요청하신 순서)

```
[0] 첫 진입: 생일 케이크 인트로 (Canva 제작 영상, 6~8초, 무음 자동재생)
      화면 중앙 "선물 열기 🎁" 버튼 ← 사용자가 한 번 누름 (= 소리 재생 허용 제스처)
[1] 제품 영상 (첨부 영상, 소리 켜짐, 우상단 음소거·건너뛰기)
[2] 영상 끝 → 마스크 전환(초 불꽃이 원형으로 커지며 화면을 연다) → 상세 스크롤 페이지
```

- **소리 자동재생 규칙**: 모든 모바일·데스크톱 브라우저는 사용자가 한 번 누르기 전에는 소리 있는 자동재생을 막는다. 그래서 [0]은 무음으로 돌고, "선물 열기"를 누르는 순간 [1]을 소리와 함께 재생한다(요청하신 "영상 소리 재생"을 실제로 가능하게 하는 유일한 방법).
- 두 번째 방문부터는 인트로를 건너뛰고 "인트로 다시 보기" 버튼만 둔다(localStorage).
- 건너뛰기는 언제나 가능, `prefers-reduced-motion`·데이터 절약 모드에서는 [0][1]을 포스터 이미지로 대체.
- 영상은 모바일용 720p(H.264, 3~5MB)·데스크톱용 1080p 두 벌, `<video playsinline>` + 포스터.

**Canva 연동**: 이 세션에 Canva 도구(디자인 생성·영상 생성·내보내기)가 연결돼 있다.
- 1안(추천): Canva에서 "생일 케이크 + 촛불 + UNI&CORE 로고" 세로/가로 영상을 생성 → MP4로 내보내 `/public/birthday/intro-*.mp4`로 사용.
- 2안: 사용자가 Canva에서 직접 만든 영상 파일을 전달.
- 사이트가 방문할 때마다 Canva를 실시간 호출하는 방식은 하지 않는다(속도·비용·Canva 로그인 필요).

## 3. 벤치마크 — trionn.com 에서 가져올 것

조사 결과 사이트 소스(스크립트)를 직접 읽을 수는 없었다. 화면 문구로 확인된 것은 "hold to blast(길게 눌러 터뜨리기)", "Dare ⚡ to touch the lines(포인터에 반응하는 선)", 대형 타이포 히어로, 프로젝트 카드 그리드다. 이를 바탕으로 같은 계열 기법을 적용한다.

| trionn 계열 기법 | 이 페이지 적용 |
|---|---|
| 초대형 키네틱 타이포 | "FIRST / BIRTHDAY" 글자가 스크롤에 따라 3D로 갈라지며 제품이 그 사이로 등장 |
| 길게 눌러 터뜨리기 | **"길게 눌러 초 끄기"** — 누르는 동안 촛불이 흔들리다 놓으면 연기→콘페티→제품 공개 |
| 포인터에 반응하는 선 | 배경의 미세한 금빛 선(=피부결·콜라겐 섬유 은유)이 커서·손가락을 따라 휘어짐 (WebGL 셰이더) |
| 부드러운 관성 스크롤 + 고정(pin) 장면 | Lenis + GSAP ScrollTrigger 스크럽 |
| 마스크 전환 | 원형·초 불꽃 모양 clip-path 장면 전환 |
| 커스텀 커서 | 데스크톱만, "드래그해서 돌려보기" 같은 상태 라벨 |

## 4. 페이지 구성 (스크롤 스크럽 · 주요 액션 강조)

각 장면은 화면에 고정(pin)되고 스크롤 진행도(0→1)로 애니메이션을 직접 조작한다(스크럽).

| # | 장면 | 스크롤 동안 일어나는 일 | 기술 |
|---|---|---|---|
| S1 | **첫 번째 생일** | "Your skin's / FIRST BIRTHDAY" 3D 글자가 깊이에서 날아와 정렬 → 글자 사이가 벌어지며 제품 병이 회전하며 등장 | 3D 텍스트 + R3F 제품 |
| S2 | **초를 끄세요** | 제품 뚜껑 위 촛불. 길게 누르면 불꽃이 커지고, 놓으면 연기·콘페티 후 뚜껑이 열림 | 입력 인터랙션 + 파티클 |
| S3 | **제품 360°** | 화면 중앙 제품을 손가락/마우스로 돌려보기, 스크롤하면 자동으로 한 바퀴 | R3F + OrbitControls (회전만) |
| S4 | **성분이 하나씩 켜진다** | PDRN → 성장인자 4종 → 펩타이드 2종: 각 성분 이름이 스크램블 텍스트로 해독되며 3D 분자 구조가 크림 속에서 떠오름 | 스크램블 텍스트 + 인스턴스 메쉬 |
| S5 | **텍스처** | 크림 질감 클로즈업 영상/이미지를 스크롤로 프레임 단위 재생 | 이미지 시퀀스 스크럽 (자료 대기) |
| S6 | **근거** | 인체적용시험 수치가 카운트업 (상세페이지 원문 그대로, 출처·조건 표기) | 숫자 카운터 |
| S7 | **매일 밤의 의식** | 사용법 3단계: 진주알 1개 → 얼굴 → 목, 손동작 라인 애니메이션 | SVG 경로 드로잉 |
| S8 | **MEDIDERMA 연결** | "내 피부 점수 확인하고 생일 케어 시작하기" → /analyze, 구매 → 공식몰 | CTA |

**3D 텍스트 (각 설명에)**: 영문 헤드라인은 실제 3D 지오메트리(Text3D), 한글·다국어 문장은 이미 사이트에 있는 CSS 3D 입체 글자(DepthText)를 써서 모든 언어에서 깨지지 않게 한다. 한글 3D 지오메트리는 폰트 파일을 글리프 단위로 잘라 쓰면 가능하지만 용량이 커서 헤드라인 몇 글자로 제한.

## 5. 3D 제작 — 적용 범위 판단

| 방법 | 가능 여부 | 장점 | 한계 | 판단 |
|---|---|---|---|---|
| **Claude 내부 (react-three-fiber 코드로 직접 모델링)** | ✅ 지금 바로 | 병 모양을 코드로 만들고 첨부 제품 사진을 라벨 텍스처로 입힘. 용량 작음(~100KB), 완전 제어, 워터마크 없음 | 실사급 디테일(굴곡·각인)은 제한 | **메인으로 채택** |
| **이미지→3D 생성 (Higgsfield 3D 도구, 이 세션에 연결됨)** | ✅ 시도 가능 | 제품 사진 1장으로 GLB 메쉬 생성 → R3F에 로드 | 정면 단일 사진 품질에 좌우, 글자 라벨이 뭉개질 수 있음 | 제품 사진 받으면 **시험 생성 후 비교** |
| **Spline** | ⚠️ 조건부 | 브라우저 3D 에디터, 이미지→3D(AI), 회전·호버·스크롤 이벤트, Next.js용 `@splinetool/react-spline` | ① 무료 플랜은 Spline 로고 워터마크 → **Hobby($12~15/월) 이상 필요** ② Claude가 Spline을 조작하려면 Spline MCP 서버 + 사용자 로그인된 편집기 탭이 필요(완전 자동 아님) ③ 장면 파일이 무거워 모바일 성능 목표(90점)와 충돌 | **보조**: 사용자가 Spline 계정이 있으면 S3 제품 회전 장면만 Spline으로 비교 시안 |

결론: **코드 기반 R3F를 기본**으로 하고, 제품 사진이 오면 이미지→3D(Higgsfield)를 시험해 더 나은 쪽을 쓴다. Spline은 계정·플랜이 준비되면 S3에 한해 비교한다.

## 7. 모바일·반응형 규칙

- 기준 폭 360 / 390 / 768 / 1280. 세로 화면은 고정 장면을 화면 높이(`svh`)에 맞춤.
- 모바일은 3D 렌더 해상도 DPR 최대 1.5, 파티클 수 1/3, 그림자 끔.
- GPU 없는 기기·데이터 절약·저사양 → 3D 대신 고품질 정지 이미지 + CSS 모션(이미 MEDIDERMA에 적용한 판별 로직 재사용).
- 터치: 길게 누르기(S2)는 진동 피드백(`navigator.vibrate`), 회전(S3)은 한 손가락 드래그, 스크롤과 충돌하지 않게 가로 드래그만 회전.
- 성능 예산: 모바일 Lighthouse 성능 90+, CLS 0, 첫 화면 JS 200KB(gz) 이하, 3D·영상은 장면 진입 직전에 지연 로딩.
- 9개 언어: 1차 한국어, 문구는 기존 언어 파일 구조로 추가해 이후 번역.

## 8. 기술 스택

- Next.js 15 (기존 MEDIDERMA 앱) · `/birthday` 라우트
- 스크롤: **GSAP + ScrollTrigger**(스크럽·고정) + **Lenis**(관성 스크롤) — 기존 framer-motion과 공존, 이 페이지에서만 로드
- 3D: three.js + @react-three/fiber + drei(이미 설치됨) · 필요 시 GLB(Draco 압축)
- 텍스트: 자체 SplitText(글자·단어 분리), 스크램블, CSS 3D DepthText, Text3D
- 셰이더: 금빛 선 필드(포인터 반응), 크림 질감 노이즈
- 영상: MP4(H.264) 모바일/데스크톱 2벌 + WebM, 포스터 이미지
