## S1 REVEAL · 제품 등장 (스크롤 1.5×)
- 시작: 제품 화면 오른쪽 아래 30% 크기, 반쯤 어둠.
- 중간: 화면 중앙으로 이동하며 크기 70%, 림 라이트 켜짐. 좌측에 "MEDIDERMA" 대형 글자가 깊이에서 등장.
- 종료: 제품 중앙 정지, 제품명·용량 [P] 라벨이 마스크 리빌.

## S2 ROTATE · 360° (스크롤 2×)
- 시작 0° → 중간 180°(후면 라벨 [P]) → 종료 360°.
- 이 구간에서도 드래그하면 사용자가 직접 돌릴 수 있고, 손을 떼면 스크롤 각도로 부드럽게 복귀.
- 텍스트: "PRECISION BEAUTY" 글자 띠가 제품을 원통형으로 감싸며 반대로 회전.

## S3 ZOOM · 디테일 (스크롤 1.5×)
- 카메라가 라벨/뚜껑/텍스처 순서로 3개 포인트에 접근 [P].
- 포인트마다 핫스팟(●) — 클릭/탭 시 정보 카드(실제 문구만).

## S4 ANATOMY · 분해 (스크롤 2×) [P]
```
     ▁▁▁  뚜껑         ← y+120
     ───  내캡         ← y+60
    ▐███▌ 용기         ← 0
     라벨 띠가 바깥으로 풀림
```
- 실제 구성 요소 수만큼만 분리(자료 확인 전에는 뚜껑·용기 2요소로 가정하고 시안 표시).
- 각 요소 옆 라벨 라인이 그려지며 이름 등장.

## S5 FORMULA · 성분 (스크롤 성분 수 × 1×)
- 성분마다 한 화면: 제품 주변에 해당 성분 3D 텍스트 + 과학 시각화
  - 예: 분자 구조(인스턴스 구체+결합), 파동(사인 필드), 입자 흐름.
- 성분명·설명은 **상세페이지 원문 그대로** [P]. 효능 과장 표현 금지.
- 모션 매핑: 첫 성분 = 입자 재결합 타이포, 두 번째 = 금속 셰이더 흐름, 세 번째 = 글자 띠 감싸기(DESIGN_SYSTEM 3장).
