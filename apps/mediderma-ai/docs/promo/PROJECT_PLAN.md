## 3. 브랜드 디자인 방향

- 콘셉트: **MEDIDERMA — THE FUTURE OF SKIN SCIENCE.** 고급 화장품의 미니멀리즘 + 미래형 바이오 사이언스 연구소.
- 금지: 쇼핑몰형 카드 나열, 흔한 그라데이션, 템플릿 히어로.
- 우선: 초대형 타이포, 깊이감 있는 공간, 빛의 이동, 정교한 재질, 영상↔3D의 끊김 없는 전환.
- **두 세계관의 공존 (결정 필요)**
  - 사이트 공통(헤더·분석·리포트): MEDIDERMA SKIN IQ 화이트·실버 + 브랜드 블루 — 오늘 적용한 브랜드.
  - 프로모션 경험(`/experience`): 프롬프트 컬러(Deep Black·Medical Green·Champagne Gold·Ivory)를 **스코프 테마**로 적용(지금 기술 장면에 쓰는 `.theme-dark` 와 같은 방식).
  - 진입·이탈 시 색이 바뀌는 지점은 영상/마스크 전환으로 처리해 이질감을 줄인다.

## 7. 3D 오브젝트 제작 계획

| 경로 | 무엇을 | 누가 | 판단 |
|---|---|---|---|
| A. Spline | 제품 모델·재질·조명·인터랙션 씬, 이미지→3D(AI) | Spline 편집기(사용자 계정 로그인 필요). Claude는 Spline MCP로 보조 조작 가능하나 완전 자동은 아님 | 무료 플랜은 Spline 로고 워터마크 → **Hobby 이상**. 자체 호스팅은 플랜 확인 필요 |

- 이미지→3D 후보: Spline AI 3D Generation, Higgsfield 3D(이 세션에 연결됨). 결과 비교 후 GLB 로 확정.

## 8. 영상 인트로·사운드 계획

- 원본 MP4 우선, WebM 병행, 모바일 720p 저용량(≤5MB)·데스크톱 1080p, 포스터 필수.
- 자동재생은 **무음**. SOUND ON/OFF 버튼, SKIP INTRO, 로딩 표시, 종료 후 마스크 전환.
- Save-Data·느린 네트워크(`navigator.connection.effectiveType` 2g/3g)·모션 최소화 → 영상 대신 포스터 + 짧은 페이드.
- 재방문: 인트로 자동 생략(설정 저장), "인트로 다시 보기" 제공.
- 영상 제작 보조: Canva(타이틀·로고 애니메이션), Higgsfield(시네마틱 보강·업스케일) — **원본 영상이 있을 때 보강용**으로만.

## 12. 성능 최적화 계획

- `/experience` 는 별도 번들: GSAP·Lenis·three 는 이 경로에서만 로드, 메인 `/` 성능 영향 0.
- 예산: 모바일 Lighthouse 성능 90+ 목표(영상·3D 페이지 특성상 최소 80), 접근성 100, CLS 0, 첫 화면 JS ≤ 200KB(gz), GLB ≤ 1.5MB(Draco), 영상은 첫 화면 이후 스트리밍.
- GPU 없는 기기·저사양: 3D → 고품질 정지 이미지 + CSS 모션(이미 메인에 적용한 판별 로직 재사용).
- 3D 렌더 DPR ≤ 1.5(모바일), 화면 밖에서는 렌더 정지(`frameloop="demand"`), 셰이더는 보일 때만.
