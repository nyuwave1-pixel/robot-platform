### 한 줄 콘셉트
특수부대 **SQUAD 07**이 무장 조직 **BLACK COBRA**가 점령한 섬에 야간 상륙해, 정글·기지·지하 연구시설을 거쳐
지휘관 **VIPER**를 제거하고 헬기로 탈출한다.

### 핵심 재미 (디자인 필러)
1. **선택하는 교전** — 소음기·야간투시경으로 조용히 처리할지, 경보를 울리고 정면 돌파할지 플레이어가 고른다.
2. **무게 있는 총기** — 발사체 탄도, 거리 감쇠, 부위 배율, 반동 패턴. 무기마다 DPS 모델이 화면과 테스트에 똑같이 쓰인다.
3. **분대와 함께 싸우는 감각** — 동료 3명(REAPER·NOMAD·ATLAS)이 따라오고, 사격하고, 무전으로 말한다.
4. **환경이 바뀌는 캠페인** — 미션마다 시간대·날씨·지형이 다르다(밤 해변 → 새벽 정글 → 폭풍 기지 → 지하 → 황혼 비행장).

## 2. 세계관·스토리

- **무대**: 가상의 섬(1.2 km × 1.2 km). 남쪽 해변 → 중앙 정글 → 북쪽 군사기지 → 지하 바이오 연구시설 → 비행장·항구.
- **아군**: SQUAD 07 — 플레이어 + REAPER·NOMAD·ATLAS. 무전 콜사인 COMMAND, 탈출 헬기 ANGEL 1-2.
- **적**: BLACK COBRA — 섬을 점거하고 지하에서 생물학 샘플을 연구하는 무장 조직. 수장은 COMMANDER VIPER.
- **흐름**: 침투 → 통신 차단 → 기지 정보 탈취 → 지하시설에서 샘플·데이터 확보 → 지휘관 제거·탈출.

## 4. 플레이어 시스템

### 4.1 이동·자세
- 걷기 / 달리기(Sprint-to-fire 지연) / 앉기 / 엎드리기 / 점프.
- 엄폐: 앉거나 엎드린 상태로 허리 높이 이상 물체에 붙으면 **엄폐 상태** — 적 명중률 감소, 조준 시 피킹.
- 무기 무게가 이동 속도와 조준(ADS) 속도에 영향.

### 4.2 사격 모델
- 모든 탄은 **시뮬레이션되는 발사체**(초기 속도·중력·공기저항). 예광탄 표시.
- 피해 = 거리 감쇠 × 부위 배율(머리 2.6 / 몸통 1.0 / 팔다리 0.72). 몸통 피해는 방어구가 50% 흡수.
- 반동: 수직 킥의 55%는 누적, 45%는 자동 복귀. 연사가 길어지면 좌우로 흔들림.
- 탄퍼짐 = 지향/조준 × 자세 × 이동 × 공중 + 연사 블룸 + 제압.
- 유리 관통, 폭발은 반경 감쇠 + 엄폐 뒤 25%, 드럼통·차량 연쇄 폭발.

## 5. 적·아군 AI

### 5.1 적 종류

| 종류 | 체력/방어구 | 행동 | 역할 |
|---|---|---|---|
| SENTRY | 90 / 0 | cover — 엄폐 후 피킹 | 기본 보초 |
| ASSAULT | 110 / 35 | push — 엄폐하며 전진 | 압박 |
| SNIPER | 80 / 0 | hold — 고정 저격 (시야 190 m) | 감시탑·고지 |
| HEAVY GUNNER | 260 / 160 | suppress — 제압 사격 | 탱커 |
| COBRA ELITE | 150 / 90 | flank — 측면 우회 + 수류탄 | 정예 |
| APC | 950 | hold — 포탑 | 차량 (폭발물 필요) |
| COMMANDER VIPER | 950 / 320 | flank + 수류탄 | 최종 보스 |

종류마다 장비 키트·위장무늬·헬멧이 다르고 실루엣으로 구분됩니다(v0.7, v0.12).

### 5.2 인지와 상태
- 인지 = 시야 거리(야간·자세·날씨·난이도 보정) × 시야각 × 가시선 + 청각(발소리·총성·폭발).
- 상태: `PATROL → SUSPICIOUS → SEARCH → COMBAT ↔ RETREAT`.
- 분대 경보: 첫 발견 시 48 m 안 같은 분대에 전파. 발견자가 5초 살아 있으면 무전으로 증원 호출.
- 엄폐 탐색: 주변 충돌체 중 위협 반대편 지점을 점수화.
- **길찾기 (v0.15)**: 평소엔 직진, 막혀서 0.35초 이상 진척이 없으면 0.5 m 격자 A*로 경로를 구해 따라감. 실패 시 옆걸음 회피.

### 5.3 아군 분대
- REAPER·NOMAD·ATLAS가 대형을 유지하며 따라옴(막히면 경로 재계획).
- 교전 시 "Weapons free" 후 사격, 처치 시 무전 대사. 쓰러지면 18초 후 복귀.

## 7. 아트·사운드 방향

### 7.1 비주얼
- **사실적인 저폴리** — 형태는 Blender 스크립트로 모델링하고, 질감은 CC0 실사 텍스처(Poly Haven 12종)로 입힘.
- 조명: 방향광 + 환경광(IBL) + 베이크 AO + 디테일 노멀 + 반사 수면 + 블룸. 프리셋 5종(night/dawn/storm/dusk/facility) 사이를 보간.
- 포스트 효과: 야간투시, 열화상, 비네트, 피격, 수중, 페이드.
- 시네마틱: 미션별 카메라 샷 시퀀서, 미션 05는 Blender Cycles로 미리 렌더한 영상.

### 7.2 3D 에셋 (Blender 스크립트 53종, 프로젝트 소유)
- 병사(얼굴·손·무릎 관절·전투복·장구류, 종류별 키트, 거리 LOD)
- 총기 12종(총구·조준선·왼손·탄창 위치 마커 포함)
- 차량: 상륙정, 헬기, APC, 트럭 / 구조물: 감시탑, 통신탑, 레이더, 크레인, 화물선, 부두, 깃대 등
- 소품: 상자, 발전기, 랙, 문, 펜스, 모래주머니, 대전차 장애물 / 식생: 야자수, 활엽수, 바위 절벽
- 최적화(v0.13): 반지름 기반 분할 수 제한 → 전체 삼각형 120k → 104.5k(−13%)

### 7.3 사운드
- 기본은 WebAudio **절차 합성**(총성·폭발·발소리·환경음, 3D 패닝).
- **녹음 층 (v0.14)**: Freesound CC0 효과음 6종 + 음악 루프 3곡(메뉴·잠입·교전). 교전 중이면 교전곡, 9초간 조용하면 잠입곡으로 전환.
- 녹음을 못 불러오는 환경(단일 HTML·file://)에선 합성음으로 자동 대체.

### 7.4 에셋 정책
- 허용 라이선스: **CC0, CC-BY(출처 표기)**만. NC·ND·출처 불명·"개인용 무료" 금지. Mixamo·Fab Standard·Sonniss·Sketchfab NC/ND 사용하지 않음.
- 모든 외부 파일은 들여오는 커밋에서 라이선스 대장에 기록하고, 크레딧 화면 누락은 테스트가 막음.

## 8. 기술 구조 요약

- 전역 컨텍스트 `G`에 시스템을 등록(서로 직접 import하지 않음 → 이식 용이).
- 상태 머신: `menu → cinematic → playing ⇄ paused → dead → result`.
- 시뮬레이션과 렌더 분리 — 테스트가 렌더 없이 게임 시간을 빠르게 돌림.
- 지형: 1,200 m 하이트필드, AABB 충돌체 약 2,000개, 그리드 DDA 레이캐스트.
- 성능: 식생 인스턴싱, 정적 지오메트리 병합, 파티클·데칼 풀링, AI 거리 LOD, 셰이더 워밍업, 구역별 식생 컬링.
- 빌드: 웹(`vite build`), 단일 HTML(`build:single`), Windows(`build:win`, Electron).

## 10. 장르 벤치마크와 진입 흐름 개편 (v0.17)

### 10.1 조사 — Call of Duty 캠페인 설계에서 가져올 장르 문법
원칙: **장르 공통 문법만 참고하고 IP(이름·캐릭터·UI 디자인·로고·레벨)는 가져오지 않는다.**
출처는 위키백과 5개 문서(Call of Duty 4: Modern Warfare, Call of Duty: Modern Warfare (2019), Call of Duty, Health (game terminology), Heads-up display (video games))다. 팬 위키(훈련 미션·체력·히트마커)는 접근이 거부돼 읽지 못했다.
